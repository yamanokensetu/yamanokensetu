# Yamanokensetu Website

Professional responsive fitness and training website for **Yamanokensetu**.

## Included
- Fitness homepage
- Strength, mobility, conditioning, and functional training categories
- Training approach section
- Beginner, intermediate, and advanced plans
- Sample pricing
- About section
- Training request form
- Responsive mobile navigation
- GitHub Pages ready

## Files
- `index.html`
- `styles.css`
- `script.js`

## Publish with GitHub Pages
Upload all files to the root of the `yamanokensetu` repository.

Then go to:

**Settings → Pages → Deploy from a branch → main / root → Save**

The training plans and prices are sample content and can be replaced with your actual programs. The website photography is loaded remotely from Unsplash.
